Guide d'utilisation - Assistant Rédactionnel

🎯 Fonctionnalités principales

Menu amovible : Survolez le haut de l'écran pour accéder aux fonctions avancées (jour/nuit, sauvegarde, historique, etc.)

📝 Informations du projet

Remplissez soigneusement tous les champs pour optimiser la génération de contenu :

  • Titre : Nom descriptif pour organiser vos projets
  • Public cible : Décrivez précisément votre audience
  • Mots-clés : Termes importants à inclure
  • Ton : Style de communication souhaité
  • Description : Contexte détaillé du projet

🤖 Sélection de l'IA

Choisissez l'IA la plus adaptée à votre besoin :

  • Claude : Excellent pour l'analyse et la rédaction créative
  • GPT-4 : Polyvalent, idéal pour la plupart des tâches
  • Gemini : Performant pour la recherche et l'analyse
  • ElevenLabs : Spécialisé dans la génération audio

📱 Types de média et formats

Sélectionnez le type de contenu puis le format de sortie souhaité. L'interface propose des templates optimisés pour chaque plateforme sociale.

⚙️ Fonctions avancées

  • Panel Admin : Interface complète de gestion administrative
  • Config API : Configurez vos clés d'API pour les différentes plateformes
  • Calendrier : Planifiez vos publications
  • Historique : Retrouvez vos créations précédentes
  • Analyse : Obtenez des statistiques sur vos contenus

💡 Conseils d'utilisation

Pour de meilleurs résultats :

  • Soyez précis dans vos descriptions
  • Utilisez les infobulles pour comprendre chaque champ
  • Testez différentes combinaisons de tâches
  • Sauvegardez régulièrement vos projets
