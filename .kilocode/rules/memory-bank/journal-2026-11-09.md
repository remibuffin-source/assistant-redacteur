## 8. Transcription vocale — régression corrigée
- **Cause** : dans les modifications non commitées de `UploadArea.jsx`, la version commitée
  (qui fonctionnait) avait été cassée :
  - suppression du **redémarrage automatique** dans `recognition.onend` ;
  - ajout d'un **arrêt après 3 secondes de silence** ;
  - `no-speech` ignoré mais `onend` arrêtait quand même la dictée.
- **Correction** :
  - suppression du timeout de 3 s ;
  - redémarrage automatique sur `onend` tant que la dictée est active (Chrome coupe après
    un silence ou ~60 s) ;
  - `no-speech` / `aborted` → relance sans arrêt ;
  - erreurs fatales explicites (`not-allowed`, `audio-capture`, `network`) ;
  - refs `dictationBaseRef` / `dictationFinalRef` pour éviter les closures obsolètes ;
  - garde-fou : 60 relances max sans résultat.
- **Limite connue** : la qualité dépend du Web Speech API du navigateur. Pour une qualité
  nettement supérieure, prévoir une transcription serveur Whisper (clé `whisper` déjà
  prévue dans Config API, mais aucune route backend `/transcribe` n'existe).

## 9. Pièces jointes / images de référence dans les presets
- **Cause** : `StorageManagerAPI.loadModel()` remplaçait `config.attachedFiles` par les
  seules métadonnées serveur (`id`, `name`, `size`, `type`, `url`) → plus de base64,
  plus de `roles` (style/décor/sujet), plus de `strength`. D'où « les titres seulement »,
  vignettes absentes et cases non cochées.
- Les préréglages de type « configuration » n'incluaient pas du tout `attachedFiles`.
- **Corrections** :
  - `StorageManagerAPI.loadModel` : fusion métadonnées serveur + données riches de la config
    (les données riches priment).
  - `referenceImageStore.js` : `savePresetFiles` / `loadPresetFiles` / `deletePresetFiles`
    (IndexedDB, clé `preset:<id>`) + `normalizeAttachedFiles` (dataUrl depuis base64).
  - `MenuBar.jsx` : sauvegarde des pièces jointes dans IndexedDB à la création du preset,
    restauration au chargement, suppression avec le preset.
  - `StorageManager.js` : `attachedFiles` inclus dans les configs locales, binaires retirés
    (`stripBinaryData`) pour éviter le quota localStorage.
  - `HomeFixed.jsx` : normalisation des pièces jointes dans `loadState`.
  - `UploadArea.jsx` : vignettes **84×84** (120 px − 30 %), repli `dataUrl || base64 || url`,
    nom de fichier affiché sous la vignette, liste en **grille 2 colonnes** (1ʳᵉ à gauche,
    2ᵉ à droite) sur desktop, 1 colonne sous 720 px.
  - **SeedDream TTI** : `supportsReferenceImages = isImageMode` (au lieu d'exclure TTI).
    TTI affiche donc la grille 2 colonnes, les rôles/force et le bouton d'ajout comme les
    deux autres IA d'image. Le backend bascule automatiquement sur `v5/lite/edit` dès que
    des références sont présentes.
