## 📧 Inscription d'un nouveau compte

### ⚠️ IMPORTANT : Pas d'email envoyé !

Quand vous créez un nouveau compte :

1. **Remplissez le formulaire** d'inscription
2. **Cliquez sur "S'inscrire"**
3. **Vous êtes redirigé** vers la page de vérification
4. **Le code s'affiche** dans une boîte orange sur la page
5. **Copiez-collez** le code dans le champ
6. **Validez** → Compte activé !

**Vous ne recevrez PAS d'email** - c'est normal en développement !

## 🔧 Problèmes courants

### "Identifiants incorrects"
→ Ouvrez `init-auth.html` et vérifiez que le compte existe

### "Compte non vérifié"
→ Les comptes admin et test sont automatiquement vérifiés

### "Session expirée"
→ Déconnectez-vous et reconnectez-vous

### Cache vidé / Pas de compte
→ Ouvrez `init-auth.html` pour recréer les comptes
