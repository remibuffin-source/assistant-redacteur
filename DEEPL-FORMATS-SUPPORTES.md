# 📄 DeepL - Formats de Documents Supportés

## ⚠️ IMPORTANT

DeepL ne supporte **QUE certains formats de documents**.

**Les formats ODT, DOC, RTF ne sont PAS supportés !**

---

## ✅ FORMATS SUPPORTÉS

### **📄 Documents Microsoft Office**

- ✅ **DOCX** (Word 2007+)
- ✅ **PPTX** (PowerPoint 2007+)
- ✅ **XLSX** (Excel 2007+)

### **📝 Formats Texte**

- ✅ **TXT** (Texte brut)
- ✅ **HTML** (Pages web)
- ✅ **HTM** (Pages web)

### **📋 Formats de Localisation**

- ✅ **XLF** (XLIFF 1.2)
- ✅ **XLIFF** (XLIFF 2.1)

### **📑 Format PDF**

- ✅ **PDF** (Portable Document Format)

---

## ❌ FORMATS NON SUPPORTÉS

### **⚠️ Ces formats NE FONCTIONNENT PAS avec DeepL**

- ❌ **ODT** (OpenDocument Text)
- ❌ **ODS** (OpenDocument Spreadsheet)
- ❌ **ODP** (OpenDocument Presentation)
- ❌ **DOC** (Word 97-2003)
- ❌ **XLS** (Excel 97-2003)
- ❌ **PPT** (PowerPoint 97-2003)
- ❌ **RTF** (Rich Text Format)
- ❌ **EPUB** (eBook)
- ❌ **MOBI** (Kindle)

---

## 🔄 SOLUTIONS DE CONVERSION

### **Si vous avez un fichier ODT, DOC ou RTF**

#### **Solution 1 : Convertir en DOCX**

**Avec LibreOffice** :
1. Ouvrir le fichier ODT/DOC/RTF
2. **Fichier** → **Enregistrer sous**
3. Format : **Microsoft Word 2007-365 (.docx)**
4. Enregistrer

**Avec Microsoft Word** :
1. Ouvrir le fichier
2. **Fichier** → **Enregistrer sous**
3. Format : **Document Word (.docx)**
4. Enregistrer

---

#### **Solution 2 : Convertir en PDF**

**Avec LibreOffice** :
1. Ouvrir le fichier
2. **Fichier** → **Exporter au format PDF**
3. Enregistrer

**Avec Microsoft Word** :
1. Ouvrir le fichier
2. **Fichier** → **Enregistrer sous**
3. Format : **PDF**
4. Enregistrer

---

#### **Solution 3 : Conversion en Ligne**

**Sites de conversion gratuits** :
- [CloudConvert](https://cloudconvert.com/) : ODT → DOCX
- [Zamzar](https://www.zamzar.com/) : Tous formats → DOCX/PDF
- [Online-Convert](https://www.online-convert.com/) : Conversion universelle

## 💡 RECOMMANDATIONS

### **✅ Format Recommandé : DOCX**

**Pourquoi DOCX ?**
- ✅ Préserve la mise en forme
- ✅ Supporte les images
- ✅ Conserve les styles
- ✅ Compatible avec tous les systèmes

---

### **✅ Alternative : PDF**

**Pourquoi PDF ?**
- ✅ Format universel
- ✅ Mise en page préservée
- ✅ Fonctionne partout

**⚠️ Limitation** :
- Le PDF traduit peut avoir une mise en page différente

---

## 🔍 VÉRIFICATION AVANT TRADUCTION

### **Checklist**

Avant de traduire un document avec DeepL :

1. ✅ **Vérifiez l'extension** : .docx, .pdf, .pptx, .xlsx, .txt, .html
2. ✅ **Si ODT/DOC/RTF** : Convertir en DOCX ou PDF
3. ✅ **Taille du fichier** : < 10 MB (limite DeepL)
4. ✅ **Langue cible** : Mentionnée dans la description du projet

## ⚠️ LIMITATIONS DEEPL

### **Taille de Fichier**

**Limite** : 10 MB par document

**Si dépassement** :
```
⚠️ Erreur : Fichier trop volumineux (15 MB)
💡 Solution : 
  - Diviser le document en plusieurs parties
  - Compresser les images
  - Supprimer les éléments non essentiels
```

---

### **Nombre de Pages**

**Pas de limite stricte**, mais :
- Documents très longs peuvent prendre du temps
- Timeout possible après 2 minutes
