# Installation de Multer

Multer est nécessaire pour gérer l'upload de fichiers.

## Installation

```bash
cd backend
npm install multer
```

## Vérification

Après installation, vérifiez que `multer` apparaît dans `package.json` :

```json
{
  "dependencies": {
    "multer": "^1.4.5-lts.1"
  }
}
```

## Redémarrage

Après installation, redémarrez le serveur Node.js.
