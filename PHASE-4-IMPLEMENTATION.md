## 🎨 1. STYLE ET TON (6 options)

### **Professionnel**
**Caractéristiques** :
- Ton : Formel et structuré
- Vocabulaire : Précis, technique, spécialisé
- Structure : Logique et hiérarchisée
- Priorités : Rigueur, clarté, professionnalisme

**Utilisation** : Rapports, présentations d'entreprise, communications officielles

---

### **Créatif**
**Caractéristiques** :
- Ton : Original et expressif
- Vocabulaire : Métaphores, images poétiques, tournures innovantes
- Structure : Variée pour créer du rythme
- Priorités : Originalité, surprise, impact émotionnel

**Utilisation** : Contenus marketing, storytelling, création artistique

---

### **Académique**
**Caractéristiques** :
- Ton : Rigoureux et analytique
- Vocabulaire : Scientifique, termes techniques précis
- Structure : Arguments étayés, références, progression logique
- Priorités : Objectivité, rigueur méthodologique, argumentation solide

**Utilisation** : Articles scientifiques, thèses, publications académiques

---

### **Décontracté**
**Caractéristiques** :
- Ton : Accessible et conversationnel
- Vocabulaire : Simple, direct, familier
- Structure : Phrases courtes, style fluide
- Priorités : Proximité, authenticité, spontanéité

**Utilisation** : Blogs personnels, réseaux sociaux, communications informelles

---

### **Persuasif**
**Caractéristiques** :
- Ton : Convaincant et engageant
- Vocabulaire : Mots d'action, bénéfices clairs, déclencheurs émotionnels
- Structure : Argumentation progressive avec preuves et CTA
- Priorités : Impact, conviction, motivation à l'action

**Utilisation** : Pages de vente, publicités, argumentaires commerciaux

---

### **Informatif**
**Caractéristiques** :
- Ton : Clair et pédagogique
- Vocabulaire : Accessible, termes techniques définis
- Structure : Information progressive et structurée
- Priorités : Clarté, précision, transmission efficace

**Utilisation** : Tutoriels, guides, contenus éducatifs

---

## 📱 2. ADAPTATION MÉDIA (4 options)

### **Web/Digital**
**Optimisations** :
- **Structure** : Phrases courtes (15-20 mots), paragraphes aérés (3-4 lignes), sous-titres fréquents
- **SEO** : Intégration naturelle de mots-clés pertinents
- **Lisibilité** : F-pattern, listes à puces, espaces blancs
- **Engagement** : Liens internes, CTA clairs, éléments interactifs

**Utilisation** : Sites web, blogs, articles en ligne

---

### **Print/Papier**
**Optimisations** :
- **Structure** : Élaborée, phrases longues et complexes, paragraphes développés
- **Style** : Soutenu et littéraire, attention à la typographie
- **Lisibilité** : Pagination, marges, hiérarchie visuelle
- **Engagement** : Profondeur et réflexion sur l'immédiateté

**Utilisation** : Livres, magazines, brochures imprimées

---

### **Social/Réseaux sociaux**
**Optimisations** :
- **Structure** : Accroche ultra-forte dès les premiers mots, format scannable
- **Engagement** : Questions, émojis stratégiques, interaction
- **Hashtags** : Pertinents et tendance
- **CTA** : Clairs (like, comment, share, save)

**Utilisation** : Facebook, Instagram, Twitter, LinkedIn, TikTok

---

### **Presentation/Oral**
**Optimisations** :
- **Structure** : Points clés synthétiques, hiérarchisation claire
- **Style** : Phrases courtes et impactantes, formules mémorables
- **Visuel** : Support visuel, chiffres et données
- **Delivery** : Facilite la prise de parole et la mémorisation

**Utilisation** : Slides PowerPoint, présentations, discours

---

## 🎨 3. NIVEAU DE CRÉATIVITÉ (5 niveaux)

- Langage : Formulations éprouvées et standards
- Risque : Aucune prise de risque stylistique
- Priorité : Précision et clarté absolues

**Utilisation** : Documents légaux, rapports financiers, communications officielles

**Caractéristiques** :

- Langage : Varié tout en restant accessible
- Risque : Mesuré et calculé
- Priorité : Originalité ET clarté

**Utilisation** : Contenus web, articles de blog, newsletters

---

### **Niveau 4/5 - Créatif**
**Température IA** : 0.85

**Caractéristiques** :
- Approche : Créatif, formulations originales
- Langage : Tournures innovantes, métaphores, images
- Risque : Sort des sentiers battus
- Priorité : Originalité et impact

**Utilisation** : Contenus marketing, storytelling, réseaux sociaux

---

### **Niveau 5/5 - Très créatif**
**Température IA** : 0.95

**Caractéristiques** :
- Approche : Audacieux, innovant, surprenant
- Langage : Territoires stylistiques inédits, associations originales
- Risque : Assumé, bouscule les conventions

**Utilisation** : Création artistique, campagnes disruptives, contenu viral

## 🎯 CALCULS AUTOMATIQUES

### **Température IA (Créativité)**

```javascript
function calculateTemperature(creativity = 3) {
  const temperatureMap = {
    1: 0.3,  // Très conservateur
    2: 0.5,  // Conservateur
    3: 0.7,  // Équilibré (défaut)
    4: 0.85, // Créatif
    5: 0.95  // Très créatif
  };
  return temperatureMap[creativity] || 0.7;
}
```

**Impact** :
- **0.3** : Réponses très prévisibles et cohérentes
- **0.7** : Équilibre créativité/cohérence
- **0.95** : Réponses très créatives et surprenantes

### **Tokens maximum (Longueur)**

```javascript
function calculateMaxTokens(lengthLevel = 3, formatMaxLength = null) {
  // Si format avec limite stricte
  if (formatMaxLength) {
    return Math.ceil(formatMaxLength * 1.5);
  }

  // Sinon, selon niveau de longueur
  const tokenMap = {
    1: 200,   // 30% - Très court
    2: 500,   // 65% - Court
    3: 1000,  // 100% - Standard (défaut)
    4: 1500,  // 130% - Long
    5: 2000   // 160% - Très long
  };
  return tokenMap[lengthLevel] || 1000;
}
```

**Impact** :
- Contrôle précis de la longueur générée
- Respect des contraintes de format
- Adaptation au contexte
